# ThesisLens frontend

The ThesisLens frontend is a React, TypeScript, and Vite research interface for company financial data and thesis evidence reports. It communicates with the FastAPI backend through the Vite `/api` proxy; see the [project README](../README.md) for setup, SEC configuration, testing, and current limitations.

From this directory, run `npm install`, `npm run dev`, `npm run lint`, or `npm run build`.
